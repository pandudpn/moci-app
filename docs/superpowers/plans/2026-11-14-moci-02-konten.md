# Moci — Rencana 02: Konten — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Semua isi prototipe diekspor satu kali ke `assets/` dalam format spec: katalog, jalur tracing, halaman mewarnai, dan ilustrasi. Aplikasi memuatnya lewat model Dart yang teruji, dan `tool/validate_content.dart` menjaganya di CI.

**Architecture:**
- `tool/konten/ekspor_prototipe.dart` membaca snapshot `docs/design/prototype/`, lalu menulis `assets/content/katalog.json`, `assets/tracing/*.json`, `assets/coloring/*.json`, dan `assets/illustrations/*.svg`. Setelah dijalankan sekali, file JSON itu menjadi sumber kebenaran dan diedit langsung. Skrip ekspor tidak dijalankan ulang di CI.
- Model konten di `lib/core/content/` ditulis sebagai Dart murni tanpa import Flutter, supaya bisa dipakai aplikasi sekaligus validator.

**Tech Stack:** Dart 3 (bawaan Flutter 3.50), paket `xml` (hanya `dev_dependencies`, dipakai validator SVG), dan `vector_graphics_compiler` dari Rencana 01.

**Spec:**
- Tab Konten & Aset dan Spesifikasi Teknis di [Dokumentasi Moci](https://claude.ai/artifact/VKF6SyozUj7ZBBCFEQ9e8H).
- Sumber data: `docs/design/prototype/*.dc.html` (snapshot 14 November 2026) dan `docs/design/prototype/assets/<blob>.svg` (172 file).
- Inventaris dataset: `docs/design/notes/inventaris-konten.md`.
- Peta rencana: `docs/superpowers/plans/2026-11-14-moci-roadmap.md`.

**Bergantung pada Rencana 01:** Task 1 (proyek dan FVM), Task 5 (`AppLang`), dan Task 10 (folder `assets/illustrations/` dengan transformer, plus 41 SVG awal yang namanya sama dengan hasil ekspor di sini).

## Global Constraints

- Semua isi ikut terpasang di aplikasi, dan tidak ada yang diunduh saat aplikasi berjalan.
- Folder isi: `assets/content`, `assets/tracing`, dan `assets/coloring`. Satu entri katalog mewakili satu benda, dan setiap layar menyaring entri sesuai kebutuhannya.
- Bentuk entri katalog mengikuti contoh `kucing` di spec persis: `id`, `kategori`, `nama{id,en}`, `gambar` (`"illustrations/<id>.svg"`), `warna`, `hewan{kelompok, bunyi{id,en}, fakta{id,en}}`, `sukuKata{id, en}`.
- Jumlah isi: huruf 26; angka 50 dengan 12 benda hitung; warna 11 dengan 81 benda bertanda warna; bentuk 10; suku kata 90 (contoh untuk 41); kata Susun Kata 71 ID dan 33 EN; kalimat 18; tracing 26 huruf dan 10 angka di kotak 520 × 520; halaman mewarnai 14 di kanvas 800 × 600.
- Aturan SVG ilustrasi:
  - `viewBox="0 0 200 200"`, maksimal 12 warna isian.
  - Tanpa `<style>` atau CSS, gradien, `<image>`, `<text>`, filter, dan mask. Semua warna ditulis sebagai atribut.
  - Satu file berisi satu benda tanpa latar.
  - Nama file = id: huruf kecil tanpa spasi.
- Halaman mewarnai: setiap bagian yang bisa diwarnai adalah satu path tertutup, dan garis detail disimpan terpisah.
- Narasi:
  - Path: `assets/audio/vo/<bahasa>/<jenis>_<id>.m4a`.
  - Naskah berbentuk CSV dengan kolom nama file, bahasa, teks, dan catatan pelafalan. Naskah dibuat otomatis dengan `dart run tool/validate_content.dart --naskah`.
- Suara hewan disimpan di `assets/audio/hewan/<id>.m4a`. Setiap file audio dari luar dicatat di `assets/audio/LICENSES.csv` dengan kolom `file,sumber,URL,lisensi,tanggal unduh,catatan`.
- Anggaran: ilustrasi maksimal **4 MB**, audio maksimal **12 MB**.
- Validator dijalankan di CI di setiap pull request, dan menggagalkan build rilis kalau masih ada teks tanpa rekaman.

## Review Focus

1. **Id yang dipakai lintas dataset tetapi tidak ada di katalog**, misalnya gambar contoh suku kata atau gambar huruf EN. Aplikasi tidak boleh crash, dan validator harus menangkapnya. Dipatok di Task 5 (`referensi_gambar_ada`).
2. **Nama yang berbeda untuk id yang sama di prototipe** (`paprika`, `kado`, `eskrim`). Katalog harus memakai satu nama, dan validator mencegah konflik baru. Dipatok di Task 3 (keputusan K2) dan Task 5 (`id_unik`).
3. **Path tracing yang memakai perintah selain `M L H V C`** setelah diedit tangan. Sampler di Rencana 03 hanya mengerti kelima perintah itu. Dipatok di Task 5 (`tracing_perintah_didukung`).
4. **Isi baru ditambahkan tanpa narasi.** Mode pengembangan hanya memberi peringatan, sedangkan `--rilis` gagal. Naskah CSV memuat semua baris yang belum direkam. Dipatok di Task 6.
5. **File audio dari luar tanpa baris lisensi, atau dengan lisensi selain CC0 dan `Milik sendiri`**, misalnya suara Freesound yang diunduh manual tetapi lupa dicatat. Kondisi ini selalu galat, juga di mode pengembangan. Dipatok di Task 6 (`lisensi_audio_lengkap`).

### Task 1: Parser literal JS

**Files:**
- Create: `tool/konten/js_literal.dart`, `test/tool/js_literal_test.dart`

**Interfaces:**
- Produces: `(Object? value, int end) parseJsLiteral(String source, int start)`.
  - Membaca satu literal JS murni yang dimulai di `start`: array, objek, string, angka, `true`, `false`, atau `null`.
  - Hasilnya `List`, `Map<String, Object?>`, `String`, `num`, `bool`, atau `null`, ditambah posisi sesudah literal.
  - Melempar `FormatException` (berisi posisi dan potongan teks) kalau menemukan identifier, pemanggilan fungsi, atau operator.

Aturan yang didukung:
- String dengan kutip `'…'` atau `"…"`, termasuk escape `\'`, `\"`, `\\`, `\n`, dan `\uXXXX`.
- Kunci objek tanpa kutip (`apel: 'f3…'`).
- Koma di akhir daftar.
- Komentar `//` dan `/* */`.
- Angka negatif dan desimal.

Transformasi:
1. **Indeks blob → id** dibangun dari tema game, hewan, buah, warna, benda hitung, dan peta gambar huruf. Hasilnya 107 id, dan satu blob hanya boleh punya satu id. Tambahkan `moci` (`0b224341…`), `moci-senang` (`c6f764ab…`), dan `karyaku` (`4061ab5b…`) sebagai gambar non-katalog.
2. **`item`** (107 entri), diurutkan per kategori lalu per urutan tema prototipe:
   - `kategori` diambil dari tema (`buah`, `sayur`, `hewan`, `kendaraan`, `benda`), atau `lain` untuk keempat benda di K4.
   - `nama` diambil dari tema dulu, lalu dari dataset lain, dengan aturan K2 dan K4.
   - `gambar` = `illustrations/<id>.svg`.
   - `warna` diambil dari benda bertanda warna, dengan id warna sesuai K3.
   - `hewan` diambil dari data Hewan.
   - `sukuKata.{id,en}` diambil dari data Kata kalau kata Susun Kata sama dengan `nama` di bahasa itu (abaikan huruf besar-kecil). Selain itu `null`.
3. **`huruf`:** 26 entri `{huruf, id: {kata, gambar, bunyi, nama}, en: {…}}`, dengan `gambar` = id katalog (hasil peta gambar lalu indeks blob).
4. **`angka`:** `{maks: 50, rentang: [[1,10],[11,20],[21,30],[31,40],[41,50]], benda: [12 id dengan urutan pool]}`.
5. **`warna`:** 11 entri dengan id sesuai K3. **`bentuk`:** 10 entri dengan `jenis`, `sudut`, dan `sisi` sesuai K5.
6. **`sukuKata`:** `{konsonan: 'bcdfghjklmnprstwyz', vokal: ['a','i','u','e','o'], contoh: {id: {ba: {item: 'badak', kata: 'Badak'}, …}, en: {…}}}`.
7. **`kata`:** `{id: [{item, kata, suku}], en: [...]}` dengan urutan prototipe. **`kalimat`:** `{id, teks: {id, en}, gambar, waktu: {id: null, en: null}}` (K7).
8. **`ucapkan`:** `{id: [{kata, suku, gambar}], en: [...]}`. Suku kata tetap ditulis huruf besar seperti di prototipe.
9. **`tracing`:**
   - `huruf.json` = `{versi: 1, kotak: 520, glyph: {A: […], …, Z: […]}}`.
   - `angka.json` = `{versi: 1, kotak: 520, glyph: {'0': […], …, '9': […]}}`.
   - String path disalin persis.
10. **`pages.json`:** `{versi: 1, kanvas: [800, 600], halaman: [...]}`.
